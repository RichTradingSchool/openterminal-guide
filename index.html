OpenTerminal 설치부터 첫 사용까지
명령어 네 줄이면 브라우저에서 열립니다

이 가이드는 공부용 비공식 한국어 정리입니다. OpenTerminal 개발자·원문 작성자와 관련이 없고, 특정 종목을 사거나 팔라고 권하지 않습니다. 시세는 무료 공개 출처에서 오기 때문에 늦거나 틀릴 수 있으니 실제 투자 판단에는 쓰지 마세요.

01한눈에 보기

OpenTerminal은 주식·암호화폐 차트, 뉴스, 시장 지표를 여러 패널에 모아 보여 주는 오픈소스 도구입니다. 내 컴퓨터에서 실행하고 웹브라우저로 엽니다. 자동매매 봇이 아니라 시장을 살펴보는 분석용 작업 공간이에요. 원문은 월 2,000달러가 넘는 상용 터미널과 비교해 소개합니다.

무엇을 쓸 수 있나

  • 끌어서 옮기고 크기를 바꾸는 위젯 12종
  • 캔들 차트: 시간 단위 8종, 보조지표 6종 (SMA·EMA·VWAP·볼린저 밴드·RSI·MACD)
  • 미국 주식 히트맵과 종목 스크리너
  • 옵션 체인, 암호화폐 보드, 거시경제 대시보드, 실적·경제지표 캘린더
  • 내 컴퓨터에만 저장되는 포트폴리오 추적과 손익 계산
  • 뉴스 모음, 통합 검색, 선택 기능인 AI 어시스턴트

02준비물

  • Node.js — 앱을 실행하는 데 필요합니다. LTS 버전, 20 이상을 권장해요. nodejs.org
  • Git — 코드를 내려받는 도구입니다. Mac에는 이미 있을 수 있어요. git-scm.com/downloads
  • 터미널 — Mac은 '터미널', Windows는 PowerShell을 엽니다.
TIP · Git이 싫다면
프로젝트 페이지(github.com/ErTasselli/OpenTerminal)의 초록색 Code 버튼 → Download ZIP으로 받아 압축을 풀고, 그 폴더에서 터미널을 열어 03장 3번부터 하면 됩니다.

03설치 4단계

명령을 한 줄씩, 앞 줄이 끝난 뒤에 입력하세요. 오른쪽 위 '복사' 버튼을 누르면 터미널에 붙여넣을 수 있어요.

  • 코드 내려받기 
    git clone https://github.com/ErTasselli/openterminal.git
    openterminal 폴더가 만들어집니다.
  • 폴더로 이동 
    cd openterminal
  • 필요한 패키지 설치 
    npm install
    1~2분 걸리고 글자가 많이 쏟아지지만 정상입니다.
  • 실행 
    npm run dev
    브라우저에서 http://localhost:3000을 엽니다. 이 주소는 내 컴퓨터 안의 주소예요.
끄고 다시 켜기. 사용하는 동안 터미널 창은 열어 두세요. 끌 때는 그 창에서 Ctrl+C를 누릅니다. 다음에 켤 때는 2번과 4번만 다시 입력하면 됩니다.
오프라인은 아닙니다. 프로그램은 내 컴퓨터에서 돌지만, 시세와 뉴스를 받아 오려면 인터넷이 연결되어 있어야 해요.

04처음 둘러보기

차례대로 눌러 보면 화면이 금방 익숙해집니다.

① 종목 검색

Mac은 ⌘+K, Windows는 Ctrl+K로 검색창을 열고 회사명이나 티커를 입력해 보세요.

② 차트와 지표

차트에서 SMA20이나 RSI 같은 버튼을 눌러 지표를 켭니다. 캔들 위에 마우스를 올리면 그날의 값이 위쪽 범례에 표시돼요.

③ 히트맵

왼쪽 메뉴에서 Heatmap을 엽니다. 타일 크기는 기업 규모, 색은 오늘의 등락이에요. 초록은 오름, 빨강은 내림입니다.

④ 암호화폐

왼쪽 메뉴의 Crypto에서 시가총액 상위 코인을 보고, 하나를 눌러 차트를 엽니다.

⑤ 뉴스

News에서 내가 검색한 종목 뉴스와 GLOBAL 헤드라인을 오가며 볼 수 있어요.

⑥ 내 배치로 바꾸기

패널을 끌고, 크기를 바꾸고, 닫거나 추가해 보세요. 배치는 내 컴퓨터에 저장되어 다시 열어도 그대로 돌아옵니다.

05막힐 때

증상이렇게 해 보세요
git 명령을 못 찾아요Git을 설치하고, 터미널을 닫았다가 새로 열어 다시 입력하세요.
npm 명령을 못 찾아요Node.js를 설치하고 터미널을 새로 여세요.
3000번 포트가 이미 사용 중이에요다른 개발 도구를 닫거나 컴퓨터를 재시작한 뒤 4번을 다시 실행하세요.
패널이 비어 있어요몇 초 기다려 보세요. 무료 출처가 느리면 앱이 예비 출처로 바꿔서 불러옵니다.
화면이 안 열려요터미널에 오류 메시지가 없는지, 주소를 localhost:3000으로 입력했는지 확인하세요.

06더 써보려면

AI 어시스턴트 (선택)

본인의 Anthropic API 키가 필요하고, 사용료는 Anthropic이 청구합니다. 앱을 켜기 전에 키를 환경 변수로 지정하세요. 키가 없어도 나머지 기능은 모두 쓸 수 있고, AI 위젯에만 '사용할 수 없음'이 표시됩니다.

MAC / LINUX
export ANTHROPIC_API_KEY=여기에_키_입력
npm run dev
WINDOWS POWERSHELL
$env:ANTHROPIC_API_KEY="여기에_키_입력"
npm run dev

모델을 바꾸려면 ANTHROPIC_MODEL, 호환되는 서버를 쓰려면 ANTHROPIC_BASE_URL을 추가로 지정합니다. API 키는 다른 사람에게 보내거나 공개 저장소에 올리지 마세요.

Docker로 실행

docker compose up --build

포트폴리오 데이터는 terminal-data 볼륨에 보존되고, 포트는 기본으로 내 컴퓨터에만 열립니다.

데이터 출처와 위젯 추가

데이터 제공자는 server/src/providers 폴더에 파일 하나씩 나뉘어 있습니다. 기존 파일을 복사해 새 출처에 연결하면 돼요. 새 위젯은 web/components/widgets에 추가합니다. 프로젝트 README는 제공자 하나를 바꾸거나 더하는 데 30분쯤 걸린다고 안내합니다.

내 컴퓨터에서만 쓰기

기본 설정에서는 내 컴퓨터에서만 접속할 수 있어 같은 와이파이의 다른 기기에서는 열리지 않습니다. 외부에 공개하려면 설정을 바꾸고 보안 조치를 먼저 해야 하며, 이 프로젝트는 HTTPS를 직접 처리하지 않습니다. 패키지를 계속 최신으로 관리할 수 없다면 공개하지 않는 편이 안전해요.

07알아둘 점

  • 2026년 7월 말에 나온 프로젝트라 빠르게 바뀌고 있습니다. 거친 부분이 있을 수 있어요.
  • 시세는 라이선스 계약된 데이터가 아니라 무료 공개 출처에서 옵니다. 지연되거나 틀릴 수 있습니다.
  • 프로젝트는 개인 학습용을 내세웁니다. 시장이 어떻게 움직이는지 배우고, 차트 읽기를 연습하고, 이런 도구가 어떻게 만들어지는지 살펴보는 용도로 쓰세요.
